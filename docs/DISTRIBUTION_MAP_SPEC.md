# Distribution Network Section Specification

## Objective

Show Alcho's distribution reach across Indonesia in a premium enterprise-grade presentation.

The section should increase trust among:

- HORECA clients
- OEM partners
- Distributors
- Investors

The visual quality should feel comparable to:

- Ajinomoto
- Nestlé Professional
- Unilever Food Solutions
- Kerry

---

## Current Problems

The existing implementation uses abstract placeholder island shapes.

Issues:

- Indonesia is not recognizable.
- Appears unfinished.
- Lacks credibility.
- Does not communicate business scale.
- Weak visual hierarchy.

This implementation should be replaced completely.

## Map Requirements

Use a real Indonesia SVG map.

Required regions:

- Surabaya (HQ)
- Bali
- Lombok
- Yogyakarta
- Madiun
- Kalimantan Selatan

Do not use placeholder island shapes.

Indonesia must be visually recognizable.

---

## Distribution Routes

Create animated routes from Surabaya to all active regions.

Animation:

- Draw line effect
- Subtle glow
- Trigger on scroll

Do not use excessive motion.

## Marker Behavior

- Fade up
- Route drawing
- Counter animation
- Marker reveal

- Bounce
- Cartoon effects
- Excessive parallax
